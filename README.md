It then calculates the final average using a weighted formula and checks if the student has achieved at least 50%. If they have, the program tells them they qualify. If not, it tells them they do not qualify.

This was one of my early programming projects, originally written while learning the basics of C#. It was later cleaned up and improved after gaining a better understanding of coding, input handling, and structured console applications. The project is now integrated with Docker, making it easy to build and run in any environment.
